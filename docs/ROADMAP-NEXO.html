Modelo do produto (decidido em 23/10/2026)

O Nexo é uma assinatura self-service: o dono do negócio tem a própria conta, paga a mensalidade e usa a ferramenta sozinho para melhorar o negócio. A equipe do Nexo administra a plataforma e pode cadastrar o perfil do cliente para facilitar o começo. A especificação original falava de uma agência cuidando dos clientes; as funções continuam as mesmas, mas quem usa passa a ser o dono do negócio, e a fase Assinatura reúne o que falta para vender. A IA escreve rascunhos para o próprio dono (respostas, posts, descrição), com o custo embutido no plano. O PostgreSQL entra quando faltar escala (mais de um servidor ou relatórios de todos os assinantes); cada cliente já tem um banco separado.

Como ler este arquivo

Cada item foi conferido no código, não estimado. A base é a especificação do módulo de Google Meu Negócio (36 funções do Semrush Local, com prioridade P1, P2 e P3) e o rebranding de docs/PROMPT-CLAUDE-CODE.md. O número entre colchetes, como [13], é a linha do mapa de funções da especificação. Feito por outro caminho marca o que a especificação pedia de um jeito e foi resolvido de outro; por exemplo, o agendamento consulta a DataForSEO a cada minuto em vez de receber postback.

A saúde do código hoje: checagem de tipos, lint, build e os 524 testes do apps/web passam (rode com --testTimeout=30000 em disco lento ou OneDrive), e os 271 testes Python passam no Python 3.12 (ambiente .venv na raiz).

Caminho mais curto até vender a assinatura

  1. Pedir hoje o acesso à API do Google Business Profile. A análise leva de 1 a 4 semanas e trava os módulos de agente, avaliações e otimização.
  2. Contas isoladas: cada cliente com login próprio vendo só o próprio negócio, e o papel de administrador para a equipe do Nexo.
  3. Passar o token de teste do Mercado Pago e testar a cobrança no ambiente de teste (o código já está pronto).
  4. Painel simples do dono do negócio, com as ferramentas avançadas só para administradores. Feito.
  5. Contratar servidor e domínio e publicar seguindo docs/DEPLOY-NEXO.md, com o SMTP configurado.
  6. Escolher o modelo de IA para os rascunhos de resposta e os posts.

Fora do escopo, por decisão

[34] Distribuição em 70+ diretórios, [35] supressão de duplicados nos diretórios e [36] diretórios médicos dos EUA. Eles não entram na conta. A especificação sugere vender isso como serviço de implantação manual (Apple Business Connect, Bing Places, Facebook, Waze), com um checklist no sistema; esse checklist aparece no módulo 16.

Para marcar algo como pronto, mude o s: do item no bloco ROADMAP no fim deste arquivo. Os valores são ok, parcial, outro e falta. Itens com g:true dependem da API do Google. Os percentuais se recalculam sozinhos: pronto e outro caminho contam 1, parcial conta 0,5 e, quando um item tem micro-tarefas, são elas que contam.
