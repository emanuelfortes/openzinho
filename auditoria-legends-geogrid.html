Auditoria Plano SaaS

Visão 1 · O que é, em poucas palavras

Mostra em que posição uma empresa aparece no Google Maps quando alguém pesquisa (ex.: “pizza”) de vários pontos diferentes da cidade, e transforma isso em um mapa colorido e um relatório PDF.
1. Você diza empresa e o serviço
2. Ele criauma grade de pontos no mapa (ex.: 17×17)
3. Ele perguntaao Google “quem aparece aqui?” (via DataForSEO, pago)
4. Você recebemapa de calor + PDF
  • Verde = a empresa aparece no topo naquele ponto. Vermelho = não aparece.
  • Serve pra decidir: em que bairros estou fraco? em qual serviço?
  • É uma alternativa gratuita ao Local Falcon: você só paga a pesquisa (≈ US$ 0,17 por mapa 17×17).
  • Roda no seu computador. Sem assinatura, sem servidor, sem coleta de dados.
  • Ele mede; quem interpreta e recomenda é você (ou o agente de IA).

Passo 1 · Ver a demo no navegador (5 min, grátis)

Abra o PowerShell dentro da pasta do projeto.

corepack enable
corepack prepare pnpm@10.33.0 --activate
pnpm install --frozen-lockfile
pnpm dev
Abra o endereço que aparecer (ex.: http://127.0.0.1:5173).
Passo 2 · Gerar um PDF de exemplo (10 min, grátis)
  1. Instale o Python 3.12 em python.org/downloads e marque “Add python.exe to PATH”.
  2. Feche e reabra o PowerShell e rode:
python -m pip install -r requirements-report.txt
python tools/strategy_report.py --config examples/reports/urban-dentist.json --output-dir runs/first-report --proof --require-pdf-qa
Abra runs/first-report/report.pdf.

Se o Windows abrir a Microsoft Store ao digitar “python”: Configurações › Apps › Configurações avançadas › Aliases de execução › desligue “python.exe”.

Passo 3 · Pesquisa real de uma empresa (pago, centavos)
  1. Crie conta em dataforseo.com e coloque créditos.
  2. Copie .env.example para .env e preencha DATAFORSEO_USERNAME e DATAFORSEO_PASSWORD. Nunca compartilhe esse arquivo.
  3. Instale o motor de pesquisa e os mapas de rua:
python -m pip install -r requirements-dataforseo.txt
python -m pip install -r requirements-basemaps.txt
python -m playwright install chromium
python tools/geogrid_doctor.py --dataforseo --reports --basemaps
  1. Rode primeiro só a estimativa (não gasta nada). Só depois execute com --execute e --confirm-cost-usd (trava de segurança contra gasto).

Caminho mais fácil: peça ao agente de IA (Claude) “faça um estudo da empresa X” — ele segue o roteiro docs/STUDY-RECIPE.md, escolhe 3 a 5 buscas, mostra o custo e pede sua confirmação antes de gastar.

Pontos de atenção
  • O demo do navegador só mostra dados de exemplo; ainda não abre suas próprias pesquisas (está no roadmap).
  • Estimativa de custo é do programa, não um limite garantido pelo DataForSEO. Confira o preço no site deles.
  • macOS não foi testado oficialmente; Windows e Linux sim (271 testes passando).
  • Mapas reais precisam de internet; se falharem, o relatório para em vez de entregar mapa vazio.

1 · A decisão

Vamos pelo Caminho B: SaaS. O cliente entra num site com login, pede a pesquisa sozinho e vê o mapa e o PDF. O motor atual (Python) é reaproveitado; construímos o sistema web em volta dele.
Caminho A · você opera

Você faz a pesquisa e envia o PDF. Começa hoje, mas não escala.

Caminho B · SaaS ✔ escolhido

O cliente usa sozinho. Exige desenvolvimento, mas escala para muitos clientes.

Dica: enquanto o SaaS é construído, dá para vender no modelo A, com link de assinatura do Mercado Pago, para gerar caixa e validar.

3 · Como as peças conversam

Cliente clica "pesquisar"
   │
   ▼
Next.js (Vercel) ── confere login (Clerk) e créditos (Neon)
   │  grava a tarefa na fila (Neon)
   │  avisa o motor (chamada HTTP)
   ▼
Motor Python (Cloud Run Jobs / VPS)
   │  DataForSEO → ranking → mapa → PDF
   │  salva PDF no Vercel Blob e resultado no Neon
   ▼
Painel do cliente mostra mapa + PDF

Mercado Pago ──webhook──► Next.js ──► Neon (libera/bloqueia créditos)

Next.js não substitui o Python: o Next cuida de telas, login e pagamento; o Python faz o trabalho pesado.

5 · Pagamento: Mercado Pago Assinaturas

  1. Criar os planos (ex.: Básico, Pro) com preço e frequência mensal.
  2. O cliente assina pela página do Mercado Pago (API preapproval).
  3. O webhook avisa o Next.js a cada cobrança aprovada, recusada ou cancelada.
  4. O Next.js atualiza o Neon: pagou, recebe os créditos do mês; não pagou, acesso bloqueado.

*Estimativa do projeto (≈ US$ 0,17 por mapa 17×17 na fila Standard). Os preços dos planos são só ilustração. Cartão de crédito é garantido; Pix Automático e boleto devem ser confirmados no painel. Use o sandbox para testar. O Mercado Pago não emite NF de serviço: usar NFE.io, eNotas ou o sistema da prefeitura.

Descartados
  • Railway: o grátis é só teste; depois ~US$ 5/mês (boa opção paga).
  • Oracle Free: cadastro difícil, você administra tudo, risco de perder a máquina.
  • Render Free: pouca memória para o Chromium.
Por que o motor fica fora da Vercel
  • Chromium é pesado demais para as funções da Vercel.
  • Uma pesquisa pode levar minutos, e as funções têm tempo máximo.

7 · Regra de ouro do motor (para migrar fácil)

  • Tudo em Docker: a mesma imagem roda no Cloud Run e na VPS.
  • Um comando por tarefa: processar --job-id 123, chamado direto pelo Cloud Run.
  • Modo espera para a VPS: um loop que lê a fila no Neon e chama o mesmo comando.
  • Configuração só por variáveis de ambiente: DataForSEO, Neon, Blob. Na migração, basta copiar.
  • Não consultar o Neon a cada segundo: senão ele nunca desliga e gasta o plano grátis. O Next.js avisa o motor.

9 · Cuidados que não podem ser esquecidos

  • Senha do DataForSEO fica só no motor (variáveis de ambiente). Nunca no navegador nem no código.
  • Créditos por cliente: ninguém gasta mais no seu DataForSEO do que pagou.
  • Leaflet no Next.js: carregar só no navegador (dynamic(..., {ssr:false})).
  • Créditos dos mapas (OpenStreetMap/OpenFreeMap) sempre visíveis nos mapas e PDFs.
  • Licença MIT: manter o arquivo LICENSE original.
  • Preços e limites grátis (Vercel, Neon, Cloud Run, Mercado Pago) mudam: conferir antes de decidir.
